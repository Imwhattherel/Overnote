▣ Automatic backups and restore
A local backup is saved when Overnote starts (if due), then daily while it's running. Backups are kept locally for up to 30 days (maximum 50 copies). Cloud uploads are optional.
Saved connections: Discord — not set · GitHub — not set
Choose any local folder, including a OneDrive, Google Drive, or Dropbox-synced folder. Overnote also keeps safety backups in its own application-data folder.
⚠ Anyone who can access the Discord channel can download the backup (including note contents). Use a private channel.
⚠ Use a PRIVATE repo and a fine-grained token limited to that repo (Contents: Read & write). Each backup creates a commit.
Remote backup credentials are saved separately using Windows encryption, not inside shared or backup files. The app does not download from Discord or GitHub automatically; download the JSON file first, then select Restore.

Drag tabs into folder headings to organize them, or out to pop them out. Drag a pop-out onto the main window to dock it. Pop-outs and their monitor/position return after restart. Pop-outs show only their note, without the sidebar. Highlight text and click Remind (or Ctrl+Shift+R) to create independent reminders. Delete individual reminders in the calendar or reminder panel. Double-click to switch between edit and preview.
Storage: %APPDATA%\Overnote. On first launch, notes and settings are safely copied from the previous sticky-notes folder, which is left untouched. Chromium's caches are separate.
